# Mizan

Mizan is a personal money tracker. Log income, expenses and savings, and see your balance, net worth and monthly budget at a glance.

## Features

- **Overview**: balance, net worth, income and expense cards, a monthly budget, a budget-vs-spending chart, a category breakdown and the month's transactions
- **Transactions**: add income, expenses or savings with an amount, note and category, and browse the full history
- **How the numbers work**:
  - Balance = income − expenses − savings
  - Net worth = balance + savings

Data is stored in the browser's local storage.

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js (App Router), React, TypeScript, Tailwind CSS.
